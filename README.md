# TBH Helper

Помощник для **TaskbarHero 1.3.2**, Windows 10/11 x64.

**Автор: Hirago | Roman** — https://vk.ru/p_o_m_a_p_u_o

## Скачать

Откройте [последний релиз](https://github.com/kisstheangell-debug/TBH-Helper-Releases/releases/latest) и скачайте `TBH_Helper_<версия>_Setup.exe`.
Закройте игру, запустите установщик и выберите папку TaskbarHero с `TaskBarHero.exe`.
Загрузчик BepInEx, winhttp.dll, doorstop_config.ini, библиотеки, локальный .NET, иконки и звук включены. Системный .NET не нужен.

F8 — показать/скрыть помощник; F9 — остановить автоматизацию. На чистой установке автоматизация выключена. DLC-функции требуют купленного DLC.

## Обновление

В помощнике откройте «Обновление» → «Проверить обновления» → «Скачать обновление» → «Установить после выхода из игры».
Перед запуском проверяются размер и SHA-256 установщика. Отдельная программа ждёт закрытия игры и панели, создаёт резервную копию мода и устанавливает новую версию. Настройки получателя сохраняются.

Получателям не нужны GitHub-аккаунт и включённый компьютер автора. Обновления доступны после публикации нового релиза здесь.

В этом репозитории только готовые пакеты. Исходники, игровые сохранения, личные настройки, профили, списки отслеживания и журналы автора не публикуются.
